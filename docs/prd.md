# Insight Hub PRD（v0.1 · W1）

## 1. 用户与场景

- **用户**：中型企业（50–500 人）的内部员工；管理员负责上传与维护文档。
- **痛点**：
  1. 文档散落在网盘 / 邮件 / IM 里，找不到；
  2. 同样的问题被反复问，老员工被打断；
  3. 搜索出来的结果不可信——不知道答案从哪一段来的。

## 2. 三个核心场景

1. **单文档问答**：员工上传产品手册 → 问「退款流程要几步」→ 得到带页码引用的答案，点击引用可高亮原文。
2. **跨文档对比**：同时查两份制度文档 → 指出冲突点并分别标注出处（例如报销标准 A 与 B 不一致）。
3. **多步任务（Agent）**：让 Agent 完成「查本月差旅超标记录并起草通知邮件」，发信前需人工确认。

## 3. MVP 边界（明确不做什么）

| 做 | 不做 |
|---|---|
| PDF / DOCX / Markdown 三种格式 | 图片理解、语音输入 |
| 问答 + 引用溯源 + 拒答 | 实时多人协同编辑 |
| 单租户先跑通，再扩多租户 | 移动端 App |
| 基础评测体系 | 模型微调（W20 之后视情况） |

## 4. 成功指标（W13 验收）

| 指标 | 目标 |
|---|---|
| recall@5 | ≥ 0.85 |
| faithfulness | ≥ 0.90 |
| 无答案问题的拒答准确率 | ≥ 0.90 |
| P95 首字延迟 | < 2.5 s |
| 单次问答成本 | < ¥0.02 |
