# 测试用知识库

用于验证「上传 → 解析 → 分块」以及（W11 之后）检索问答效果。

## 文件

| 文件 | 用途 |
|---|---|
| `云雀科技-差旅费用报销手册.docx` | **主测试文件**：含多级标题 + 表格，能验证章节路径与表格抽取 |
| `云雀科技-差旅费用报销手册.pdf` | 验证 PDF 解析与**跨页**（共 2 页） |
| `云雀科技-差旅费用报销手册.md` | 纯文本版，方便直接对照答案 |
| `测试问题清单.md` | 17 道测试题，含 3 道应拒答题 |
| `generate.py` | 生成脚本（改内容后重跑即可） |

## 怎么用

1. 打开 http://8.136.244.138/ → 注册 → 「文档」页 → 上传 `.docx`；
2. 等状态变成「已完成」（约 1–3 秒）；
3. 点文档名 → 进**分块预览**，检查：
   - 父块是否按章节切开（应该 11 个左右）；
   - 表格是否**整体**成块（应该是一条带 `|` 的 Markdown 表格，而不是被切散）；
   - 每个块的「章节」是否显示为「四、住宿标准」这类路径。
4. 回到对话页提问（见 `测试问题清单.md`）。

## 当前能测到什么

| 能力 | W10 现状 |
|---|---|
| 上传、异步解析、进度推送 | ✅ |
| 章节路径、页码、表格抽取 | ✅ |
| 父子块切分 | ✅ |
| **基于文档回答** | ❌ 还没有检索（W11） |

> 所以现在提问，模型只会基于**对话历史**回答，看不到文档内容。
> 这份文档是为 W11 的检索实验准备的——那时候才能验证"回答带引用、无答案会拒答"。

## 重新生成

```powershell
cd apps/api
.\.venv\Scripts\python.exe ..\..\examples\knowledge-base\generate.py
```

改 `generate.py` 里的 `SECTIONS` 即可调整内容；三份产物（docx/pdf/md）和问题清单都从同一份数据生成。
